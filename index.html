01 / About me

More than just AI. I build the systems behind it.

My journey started with software and web development. I became interested in understanding how applications actually work: how the frontend communicates with the backend, how databases organize information, how APIs connect services, and how business rules translate into working software.

Over time, my interests expanded into more complex systems, product architecture and AI engineering. I started exploring how AI could become part of applications and perform useful tasks through tools, APIs, databases and automated workflows.

Today, I work across software development, backend engineering, database design, integrations, AI agents and automation. I don't see these as separate disciplines. They are different parts of building a complete solution.

I particularly enjoy understanding a problem from both the technical and business perspectives, then breaking it down into components that can be designed, implemented and improved.

A note about my experience

I'm intentional about representing my experience accurately. Some of my work involves implemented software systems, while other projects are in development or product-design stages. I don't claim large-scale enterprise automation experience or present concepts as launched products. I'm continuously developing my engineering skills through practical work.

X League

Sports League Platform

One of my practical software development experiences. I worked on transforming a relatively simple static website idea into a much more complete, production-oriented sports league application.

The platform includes structured data, user authentication, event management, performance calculations, athlete rankings, points and standings. Equipped with the required application logic and database structure behind the experience.

What I worked on

  • • Developing the application using SvelteKit and JavaScript.
  • • Using Supabase for authentication, PostgreSQL and backend data services.
  • • Structuring relational data for athletes, clubs, events and results.
  • • Developing scoring and ranking calculation logic.
  • • Integrating Paymob payment functionality.
  • • Designing database-driven standings and statistics.

04 / Engineering practices

I care about how systems work underneath.

A working application is not just a collection of screens. I pay attention to the architecture, data, business rules and interactions that make the whole system reliable.

01

Relational Data Modeling

Structuring entities and relationships, defining constraints and maintaining consistency between application data.

02

Business Logic

Translating real requirements into validation rules, calculations, state transitions and backend operations.

03

API Architecture

Connecting systems through structured requests, authentication, data validation and clear API contracts.

04

Data Integrity

Thinking about constraints, duplicate operations, transaction consistency and reliable state changes.

05

Integration & Error Handling

Considering external-service failures, retries, validation, logging and safe integration behavior.

06

Scalable Architecture

Separating responsibilities, avoiding unnecessary complexity and considering how systems evolve as requirements grow.
